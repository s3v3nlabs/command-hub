# Setup

This private copy expects Node.js 20+.

```bash
npm i
cp .env.example .env.local
npm run dev
```

`.env.example` contains key names only and intentionally has empty values. Add values privately in `.env.local`; never commit that file. Store secrets in Bitwarden. The Evidence Explorer can use `EVIDENCE_ROOT` for authorized local dumps when needed.
